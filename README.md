# 🎌 Anime Quiz Brasil

Plataforma profissional de quizzes de anime com foco em comunidade, segurança e performance.

## 🎯 Características Principais

- ✨ Interface moderna com tema escuro e neon
- 🎮 Sistema gamificado com XP, medalhas e rankings
- 📱 100% responsivo (mobile, tablet, desktop)
- 🔐 Segurança de nível enterprise
- ⚡ Performance otimizada (PWA)
- 💰 Monetização sem comprometer UX
- 🌐 Suporte a múltiplas categorias de anime

## 🚀 Quick Start

### Pré-requisitos
- Node.js 18+
- MongoDB Atlas ou Local
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/weliret/anime-quiz-brasil.git
cd anime-quiz-brasil

# Frontend
cd frontend
npm install
npm start

# Backend (em outro terminal)
cd backend
npm install
npm run dev
```

## 🛠️ Stack Tecnológico

### Frontend
- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS + Custom CSS
- Zustand (state management)
- React Query (data fetching)
- Framer Motion (animações)
- PWA (Workbox)

### Backend
- Node.js + Express
- TypeScript
- MongoDB + Mongoose
- JWT + 2FA
- Redis (cache)
- Socket.io (real-time)
